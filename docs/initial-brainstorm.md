# Initial brainstorm

Source: StageChase task #224, received 2026-10-21.

Create a private iPhone cookbook app for Chase using the recipes in this
repository. Required experiences include searchable list and picture-first
browsing, content-first recipe pages, quantity-free grocery additions without
duplicates, a selected Reminders destination, one-step cooking mode that keeps
the display awake, timestamped recipe notes, recipe photos, print output, and an
AI work-back dinner planner for several recipes and a fixed serving time.

The attached implementation plan at
`to-do/cookbook-mobile-app-fd47731b-f647-438e-a341-113b370e9822.md` records the
expanded requirements and decisions.
